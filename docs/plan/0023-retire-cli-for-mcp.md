## Contract
- `POST /users/me/mcp-tokens` (JWT session; MCP token → 401). Req `{"name": str, "scope": ["read", "write"]}`: name trimmed 1..100; scope non-empty, known names only, must hold `read`. 201 `{"id": "<snowflake str>", "name", "scope": ["read", "write"], "token": "applika_mcp_fake_0000…", "created_at", "expires_at"}` + `Cache-Control: no-store`. 401 AUTH-1001/1002/1011/1012, 422 GEN-1003, 429 GEN-1004, 503 AUTH-1003.
- `GET /users/me/sessions` items + `"scope": ["read", "write"] | null` (null on web + cli), `client_type: "mcp"`, `sign_in_method: "mcp_token"`, never the token. `DELETE /users/me/sessions/{id}` 204 / 404 AUTH-1043.
- `POST /mcp` JSON-RPC 2.0, `Authorization: Bearer applika_mcp_…`, `Accept: application/json, text/event-stream` → 200 `application/json`. `GET`/`DELETE /mcp` → 405. 401 `{"detail": "MCP token invalid, revoked or expired. Create a new one in Applika: Profile > MCP.", "code": "AUTH-1051"}` + `WWW-Authenticate: Bearer`. 503 AUTH-1003 + `Retry-After: 5`. 429 GEN-1004.
- Tool error: `isError: true`, text `"<detail> (<code>)"`, `structuredContent {detail, code}` = REST body. Out of scope: `{"detail": "This MCP token's scope does not allow this tool. Create a token with more access in Applika: Profile > MCP.", "code": "AUTH-1052"}`. Unknown or `cvs`-gated: `{"detail": "Not Found", "code": "GEN-1001"}`. `read` tools `readOnlyHint`; `delete` tools `destructiveHint`.
