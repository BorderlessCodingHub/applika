## Contract
No API change. Client reads pinned:
- `Application.last_step` (already on the wire, add to src/services/types/applications.ts): `{id: string, name: string, color: string, date: "YYYY-MM-DD"} | null`.
- src/lib/pipeline.ts (new): `pipelineStage(app)`: finalized_at → closed; last_step null → applied; "Initial Screen" → screening; "Offer" → offer; "Denied" → closed; other → technical. `lastUpdate = max(application_date, last_step.date)`. `STALE_DAYS = 14`; `isStale = !finalized_at && days(today - lastUpdate) > STALE_DAYS` (15 days stale, 14 not). `ago`: <7 "Nd", <8w "Nw", else "Nmo".
- Funnel: Applied = general.total_applications; Screening = conversion row interview/initial_screening; Technical = interview/technical; Offer = offer. Weekly: 8 ISO weeks of application_date, empty weeks 0. Mode: {active, passive}.
- Step days (src/lib/insights.ts `stepDays`), from avarage_days rows S = interview/initial_screening, T = interview/technical, O = offer: "Applied → Screening" = S; "Screening → Technical" = max(0, T − S); "Technical → Offer" = max(0, O − T); rounded to whole days; "—" when either stage's conversion row has total_applications 0. Board labels kept.
- Agenda item: {id, step_date, start_time, end_time, timezone, observation, application_id, company_name, role, event_type, interview_type}; next interview = first with start ≥ now in its timezone.
- Error codes: none new. Sign-in keeps `signInErrorKey` codes (AUTH-1003, 1005..1008, 1017..1019, 1046..1049, GEN-1005); Reports gated on RPT-1001, AUTH-1050.
